Question 1: Merge three NumPy arrays in three ways
Program:
import numpy as np
a = np.array([1, 2])
b = np.array([3, 4])
c = np.array([5, 6])

print("Stacked:")
print(np.stack((a, b, c)))
print("Vertical:")
print(np.vstack((a, b, c)))
print("Horizontal:")
print(np.hstack((a, b, c)))
Output:
Stacked:
[[1 2]
 [3 4]
 [5 6]]
Vertical:
[[1 2]
 [3 4]
 [5 6]]
Horizontal:
[1 2 3 4 5 6]

Question 13: Histogram and three-dimensional plotting
Program:

import matplotlib.pyplot as plt

                   'Y':[2,4,6,8,10],
                   'Z':[3,5,7,9,11]})

plt.title('Histogram')
plt.show()

fig = plt.figure()
ax = fig.add_subplot(111, projection='3d')
ax.scatter(df['X'], df['Y'], df['Z'])
ax.set_xlabel('X')
ax.set_ylabel('Y')
ax.set_zlabel('Z')
plt.title('3D Scatter Plot')
plt.show()
Output:
Displays:
1. Histogram of X values
2. Three-dimensional scatter plot of X, Y and Z.

Question 17: Use NumPy arrays to calculate weather statistics
Program:
import numpy as np

temp = np.array([20, 22, 24, 26, 28])
wind = np.array([10, 15, 20, 25, 40])

print("Mean temperature:", np.mean(temp))
print("Minimum temperature:", np.min(temp))
print("Maximum temperature:", np.max(temp))
print("Temperature standard deviation:", round(np.std(temp), 2))
print("Mean wind speed:", np.mean(wind))
print("Maximum wind speed:", np.max(wind))
print("High wind hours:", np.sum(wind > 35))
Output:
Mean temperature: 24.0
Minimum temperature: 20
Maximum temperature: 28
Temperature standard deviation: 2.83
Mean wind speed: 22.0
Maximum wind speed: 40
High wind hours: 1

Question 19: Append, slice, add and delete rows in a DataFrame
Program:
import pandas as pd

df = pd.DataFrame({'Name':['A','B','C'],
                   'Mark':[70,80,60]})
print("Original:")
print(df)

new_row = pd.DataFrame([{'Name':'D','Mark':90}])
df = pd.concat([df, new_row], ignore_index=True)
print("After appending:")
print(df)

print("Slicing:")
print(df[1:3])

df.loc[len(df)] = ['E', 75]
print("After adding row:")
print(df)

df = df.drop(1)
print("After deleting row:")
print(df)
